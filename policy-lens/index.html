IMPORTANT BOUNDARIES

Know what this tool cannot verify.

This is a heuristic, static SQL preflight. It cannot confirm deployed RLS state, a live user session, SQL view ownership, storage policies, JWT claims, privileges not in the input, or whether a policy is intentionally public. A clean report is not an independent security certification. Do not upload secrets or personal data even though processing is local. Always validate in staging using authorized test accounts.
